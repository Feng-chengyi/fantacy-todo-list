# Fantacy Todo List — 产品需求文档（PRD）

> 版本：v1.0（简单档）
> 产品经理：许清楚
> 文档语言：中文

---

## 1. 项目信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | Fantacy Todo List（桌面日历待办清单 + Live2D 桌宠陪伴） |
| 项目代号（snake_case） | `fantacy_todo_list` |
| 目标平台 | Windows 桌面 |
| 编程语言 / 技术栈 | Electron + React + Vite + TypeScript + Tailwind CSS |
| Live2D 渲染 | pixi-live2d-display |
| 数据存储 | JSON 本地存储（无账号 / 无云端 / 无广告 / 无遥测） |
| 界面主题 | 跟随系统深浅色自动切换 |

**原始需求复述**：一款带 Live2D 桌宠陪伴的 Windows 桌面日历待办应用——以月历为核心管理待办，支持优先级、重复任务、拖拽改期、完成动画、放弃状态；另有收集箱承接未定时任务；桌宠常驻桌面互动；数据完全本地保存、不联网。

## 2. 产品定义

### 2.1 产品目标

| # | 目标 | 说明 |
| --- | --- | --- |
| G1 | 让「今天该做什么」一眼可见 | 月历视图 + 今日任务高亮，优先级颜色分级，减少每日规划成本 |
| G2 | 让任务规划灵活且无负担 | 重复规则、拖拽改期、收集箱承接未定时项、放弃状态，降低用户维护成本 |
| G3 | 提供情绪陪伴感 | Live2D 桌宠常驻桌面，完成有撒花反馈，让待办管理从「工具」变「陪伴」 |

### 2.2 用户故事

| # | 用户故事 |
| --- | --- |
| US1 | 作为日常使用者，我希望打开应用就能在月历上看到今天的任务，以便快速安排当日事项。 |
| US2 | 作为多任务管理者，我希望给任务标上高/中/低优先级并用颜色区分，以便优先处理重要事项。 |
| US3 | 作为习惯养成者，我希望设置「每 N 天/每周/每月」的重复任务，并对某一天单独完成或删除，以便灵活应对突发变化。 |
| US4 | 作为拖延症用户，我希望把没想好日期的任务先丢进收集箱，等想清楚后再拖到日历，以便先清空大脑。 |
| US5 | 作为需要陪伴的用户，我希望有一个可拖拽、可缩放、点击有反应的 Live2D 桌宠，以便在完成任务时获得正向情绪反馈。 |

### 3.2 UI 设计稿说明

**整体**：Electron 主窗口（日历待办）+ 独立透明桌宠窗口（Live2D）。主窗口分三区：顶部栏、左侧收集箱/导航、右侧月历主体。

**主窗口布局**

| 区域 | 说明 |
| --- | --- |
| 顶部栏 | 应用名 + 当前年月 + 视图切换（月/周，P1）+ 主题色 + 搜索框（P1）+ 设置入口 |
| 左侧栏 | 「收集箱」入口 + 完成率统计（P1）+ 筛选（全部/未完成/已放弃） |
| 月历主体 | 7 列（周一至周日），行按周排列；今日高亮；任务卡显示标题 + 优先级色条；支持拖拽 |

**核心交互**
- **新建任务**：点击某日期 → 弹出编辑面板（标题、优先级、重复规则、备注）。
- **任务卡**：左侧优先级色条，右侧勾选按钮；勾选触发撒花动画；右键菜单含「编辑/放弃/删除」。
- **拖拽改期**：长按/拖拽任务卡跨日期移动，落点日期高亮。
- **收集箱**：独立列表，任务无日期；拖拽排序；卡片上「安排到日历」按钮 → 选日期。

**桌宠窗口**
- 透明无边框、置顶、可穿透点击区域；桌宠位于桌面角落。
- 交互：点击 → 随机动作；拖动 → 移动位置；滚轮 → 缩放；右键菜单 → 隐藏/设置/退出。

## 4. 数据模型草案

> 供架构师/工程师设计数据结构使用。存储为本地 JSON 文件。

### 4.1 任务 Task

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string (UUID) | 是 | 唯一标识 |
| `title` | string | 是 | 标题 |
| `description` | string | 否 | 备注/详情 |
| `priority` | enum | 是 | `high` \| `medium` \| `low` |
| `date` | string \| null | 是 | 安排日期 `YYYY-MM-DD`；`null` 表示在收集箱 |
| `status` | enum | 是 | `pending` \| `done` \| `abandoned` |
| `createdAt` | string (ISO) | 是 | 创建时间 |
| `updatedAt` | string (ISO) | 是 | 最后修改时间 |
| `completedAt` | string (ISO) \| null | 否 | 完成时间 |
| `repeat` | RepeatRule \| null | 否 | 重复规则，`null` 为单次任务 |
| `inboxOrder` | number \| null | 否 | 收集箱内排序权重（仅收集箱项使用） |
| `tags` | string[] | 否 | 标签（P2） |

### 4.2 重复规则 RepeatRule

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | enum | 是 | `daily` \| `weekly` \| `monthly` \| `yearly` \| `custom` |
| `interval` | number | 是 | 间隔数，如 `custom` + `interval=3` 表示「每隔 3 天」 |
| `weekdays` | number[] | 否 | `weekly` 时指定星期（0=周日…6=周六），为空表示按创建日 |
| `monthDay` | number | 否 | `monthly` 时指定日（1–31） |
| `yearMonth` | number | 否 | `yearly` 时指定月（1–12） |
| `yearDay` | number | 否 | `yearly` 时指定日（1–31） |
| `endDate` | string \| null | 否 | 重复结束日期，`null` 表示无限 |
| `endCount` | number \| null | 否 | 重复次数上限，`null` 表示无限 |

### 4.3 重复实例覆盖 RepeatOverride（单日独立操作）

> 用于实现「重复任务某一天可单独完成或单独删除，不影响其他日期」。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string (UUID) | 是 | 覆盖记录唯一标识 |
| `taskId` | string | 是 | 关联的重复任务 Task.id |
| `occurrenceDate` | string | 是 | 被覆盖的具体日期 `YYYY-MM-DD` |
| `action` | enum | 是 | `done` \| `skipped`（单独完成/单独删除即跳过） |

> 渲染规则：某日期是否显示重复任务实例 = 由 `repeat` 规则推算命中该日期，且该日期在 `RepeatOverride` 中无 `skipped`/`done` 覆盖记录。

### 4.4 收集箱项 InboxItem

> 与 Task 复用，等价于 `date = null` 的 Task；`inboxOrder` 用于拖拽排序。此处单列字段便于理解。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string (UUID) | 是 | 唯一标识 |
| `title` | string | 是 | 标题 |
| `priority` | enum | 是 | `high` \| `medium` \| `low` |
| `status` | enum | 是 | `pending` \| `done` \| `abandoned` |
| `inboxOrder` | number | 是 | 拖拽排序权重 |
| `createdAt` | string (ISO) | 是 | 创建时间 |

### 4.5 应用配置 AppConfig

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `petVisible` | boolean | 桌宠是否可见 |
| `petPosition` | {x:number, y:number} | 桌宠位置 |
| `petScale` | number | 桌宠缩放比例 |
| `confettiEnabled` | boolean | 撒花效果开关 |
| `weekStart` | number | 一周起始日（0/1） |
| `theme` | string | 预留主题标识（默认 `system`） |
